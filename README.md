# إدارة أعمالي

تطبيق ويب لإدارة الشركات: مستندات الشركة والعمال، تنبيهات الانتهاء، المالية والالتزامات الشهرية، المشاريع، التقارير، والمستشار الذكي. يعمل على الآيفون والماك بوك وأي متصفح، مع مزامنة مشفّرة عبر Google Drive.

## الملفات
- `index.html` — التطبيق كاملًا
- `manifest.webmanifest` — يجعله قابلًا للتثبيت كتطبيق
- `sw.js` — يجعله يفتح بدون إنترنت
- `icons/` — أيقونات الشاشة الرئيسية

## الرفع على GitHub
1. أنشئ مستودعًا جديدًا (مثلًا `idarat-a3mali`).
2. ارفع كل الملفات مع مجلد `icons` كما هي.
3. من Settings ← Pages اختر الفرع `main` والمجلد `/ (root)` ثم Save.
4. بعد دقيقة يظهر الرابط: `https://اسمك.github.io/idarat-a3mali/`

## التثبيت
- **الآيفون:** افتح الرابط في Safari ← زر المشاركة ← «إضافة إلى الشاشة الرئيسية».
- **الماك بوك:** في Safari: ملف ← «إضافة إلى Dock». في Chrome: أيقونة التثبيت في شريط العنوان.

## المزامنة مع Google Drive
الخطوات داخل التطبيق في «الشركات والإعدادات ← المزامنة». أضف رابط GitHub Pages (بدون المسار، مثل `https://اسمك.github.io`) في Authorized JavaScript origins، واستخدم نفس كلمة التشفير على كل الأجهزة.

## التحديث
عند وصول نسخة جديدة ارفع `index.html` و`sw.js` مكان القديمين. بعدها أغلق التطبيق وافتحه مرتين ليظهر التحديث.

## الإيماءات
- اسحب يمينًا أو يسارًا للتنقل بين التبويبات.
- اسحب للأسفل من أعلى الصفحة للتحديث والمزامنة.
- زر ؟ أعلى الشاشة يشرح الصفحة الحالية.
